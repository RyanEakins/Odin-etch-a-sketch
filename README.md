# Odin-etch-a-sketch

Name: Etch-A-Sketch for Odin Project

Description: This project consists of building a broswer version of something between a sketchpad and an Etch-A-Sketch. This webpage will consist of a 16x16 grid of square divs that allow the user to edit within the grid to create notes, drawings, or whatever they desire.
